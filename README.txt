Ganpati Ki Fauj — functional YouTube Music-style player

1. Upload/replace these files in the GitHub Pages repository:
   index.html, style.css, script.js, ganpati-hero.png, temple-bell.mp3
2. Open the GitHub Pages HTTPS site, not index.html directly from your PC.
3. Press the Play button. The site's compact player controls the YouTube playlist PLBdB2QrKw3SQ while the video surface remains hidden.
4. Previous/Next changes the YouTube playlist track. Playlist opens the full playlist in YouTube Music.
5. The bell button plays temple-bell.mp3 locally.
