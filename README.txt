Ganpati Ki Fauj — YouTube-powered music player (ToS-compliant)

1. Upload/replace these files in the GitHub Pages repository:
   index.html, style.css, script.js, ganpati-hero.png, temple-bell.mp3
2. Open the GitHub Pages HTTPS site (not index.html directly from your PC —
   the YouTube API requires a real http/https origin).
3. Press the Play button. The player controls the YouTube playlist
   PLBdB2QrKw3SQ (https://music.youtube.com/playlist?list=PLBdB2QrKw3SQ).
4. A small YouTube player thumbnail is visible next to the album art —
   this is required by YouTube's Terms of Service and is not hidden.
5. Previous/Next changes the playlist track. "Playlist" button opens the
   full playlist on YouTube Music.
6. The bell button plays temple-bell.mp3 locally.

Note on the playlist: it contains third-party copyrighted songs. Because
they're streamed live from YouTube (not downloaded/hosted by you), this
setup stays within YouTube's API terms. Don't replace this with downloaded
MP3 files of songs you don't hold rights to — that would be a copyright
violation this player is specifically designed to avoid.
