LOCAL AUDIO VERSION

This package replaces the YouTube player logic with a normal HTML5 audio player.
Audio files are in /songs/song1.mp3 through /songs/song6.mp3.

Use the existing HTML page with the updated script.js and style.css.
Make sure these files are deployed together, preserving the /songs/ folder.

The track titles are currently Song 1 ... Song 6; edit the `tracks` array in script.js
if you want custom names.
